# План разработки

## Фаза 0. Исследование и фиксация архитектуры

- [ ] Проверить текущее состояние и лицензии AnythingLLM.
- [ ] Проверить LM Studio API: chat completions, tool calling, embeddings и ограничения контекста.
- [ ] Изучить память, Skills и безопасность Hermes Agent.
- [ ] Описать варианты интеграции AnythingLLM с собственным backend.
- [ ] Составить матрицу локальности: какие данные и при каких условиях покидают машину.
- [ ] Зафиксировать ADR по UI, БД, векторному поиску и модели памяти.

## Фаза 1. Минимальный backend

- [ ] Конфигурация приложения и безопасная загрузка переменных окружения.
- [ ] Health/readiness endpoints.
- [ ] Модели User, Workspace, Project и Document.
- [ ] Локальное файловое хранилище с безопасными путями.
- [ ] Абстракция LLM provider и адаптер LM Studio.
- [ ] Интеграционные тесты с mock LLM.

## Фаза 2. Обработка документации

- [ ] Реестр форматов и валидация загрузок.
- [ ] PDF: текстовый слой, страницы, рендеринг и OCR fallback.
- [ ] Извлечение таблиц и сохранение координат.
- [ ] Формулы и математические выражения.
- [ ] Изображения и чертежи.
- [ ] Структурированное описание документа.
- [ ] Проверка качества и полноты извлечения.
- [ ] Индексация и поиск с точными ссылками на источники.

## Фаза 3. Диалог по проекту

- [ ] Контекст проекта и выбор релевантных источников.
- [ ] Цитирование файла, страницы, листа и фрагмента.
- [ ] История диалога.
- [ ] Уточняющие вопросы при недостатке доказательств.
- [ ] Тесты на точность ответов и устойчивость к prompt injection в документах.

## Фаза 4. Постоянная память

- [ ] Профиль пользователя.
- [ ] Память проекта.
- [ ] Поиск по прошлым сессиям.
- [ ] Навыки с версиями и правами.
- [ ] Подтверждение пользователем важных фактов/решений.
- [ ] Происхождение, срок актуальности и удаление записей памяти.

## Фаза 5. Инженерная экспертиза

- [ ] Интеграция выбранных модулей Project Expert AI.
- [ ] Проверки внутри раздела.
- [ ] Межраздельная согласованность.
- [ ] Нормативные проверки с редакцией норм на дату проектирования.
- [ ] Замечания с доказательствами и уровнем уверенности.
- [ ] Отчёт и трассировка каждого вывода.

## Фаза 6. Многопользовательский режим

- [ ] Аутентификация и управление сессиями.
- [ ] Проверка изоляции пользователей, проектов, файлов и индексов.
- [ ] Роли и разрешения.
- [ ] Квоты и лимиты ресурсов.
- [ ] Аудит доступа и действий.
- [ ] Резервное копирование и восстановление.
- [ ] Отдельное тестирование модели угроз.
