# Personal Expert AI

Локальная AI-платформа для работы с проектной документацией: загрузка и структурирование файлов, поиск с доказательными ссылками на источники, диалог по содержимому проекта и инженерные проверки.

> **Статус:** начальная архитектурная заготовка. Архитектурные решения и интерфейсы модулей будут уточняться по мере исследования AnythingLLM, LM Studio, Hermes Agent и существующего Project Expert AI.

## Цели

- Локальная обработка данных и использование локальных LLM через LM Studio.
- Преобразование проектной документации в проверяемую структурированную базу знаний.
- Ответы с привязкой к исходному файлу, странице, листу, таблице или фрагменту.
- Постоянная память пользователя, проекта и диалогов.
- Изолированные проекты и подготовка архитектуры к многопользовательскому режиму.
- Отделение пользовательского интерфейса от экспертного ядра.

## Принципы

1. **Local-first:** документы и запросы не отправляются во внешние облачные модели без явного решения владельца системы.
2. **Evidence-first:** существенные ответы и выводы должны опираться на проверяемые источники.
3. **Модульность:** интерфейс, оркестрация, обработка документов, память и LLM-провайдеры независимы.
4. **Изоляция:** данные каждого пользователя и проекта имеют явные границы доступа.
5. **Версионирование:** исходные документы, результаты обработки и экспертные выводы сохраняются с версиями.
6. **Human-in-the-loop:** критические инженерные решения и изменения проектной памяти подтверждаются человеком.

## Предварительный технологический контур

- **UI на первом этапе:** AnythingLLM Docker — кандидат для проверки, не жёсткая зависимость ядра.
- **LLM runtime:** LM Studio API.
- **Оркестрация и backend:** Python, FastAPI.
- **Документный движок:** развитие проверенных наработок Project Expert AI.
- **Память:** собственный Memory Engine с идеями Hermes Agent (профиль, проектная память, история, навыки).
- **Хранилища:** PostgreSQL; векторный поиск и граф связей выбираются после прототипирования.
- **Интеграции:** MCP и внутренние инструменты через контролируемые интерфейсы.

## Начальные этапы

1. Исследование AnythingLLM, LM Studio и Hermes Agent; фиксация ограничений и лицензий.
2. Проектирование доменной модели пользователей, проектов, документов, источников и памяти.
3. Прототип конвейера загрузки и анализа одного комплекта документации.
4. Чат с поиском по проекту и точными ссылками на источники.
5. Интеграция специализированных проверок Project Expert AI.
6. Подготовка к многопользовательскому развёртыванию и проверка изоляции.

## Безопасность

Не помещайте в репозиторий проектную документацию заказчиков, персональные данные, токены, пароли, файлы окружения, локальные базы данных, индексы, веса моделей или результаты проверок с конфиденциальным содержимым. Используйте шаблон переменных окружения только для имён и безопасных примеров.

## Статус разработки

На данном этапе это архитектурный каркас, а не готовое приложение. Конкретные библиотеки, схемы БД и API будут утверждаться отдельными архитектурными решениями после проверки совместимости и лицензий.
